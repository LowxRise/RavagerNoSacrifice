Set how much health Ravager spends on Twisted Mutation's charged aerial blink.

The Risk of Options slider runs from 0–10%, with 0% as the default. This is the cost at full charge; a shorter charge still costs proportionally less. The ordinary blink and other skills are untouched.

Changes apply on the next blink. Requires Ravager and Risk of Options. Built against Ravager 1.6.0. The original skill tooltip still says 10%.

For multiplayer, install it on every player's profile and use matching settings. Import the ZIP through r2modman's Settings > Profile > Import local mod.
